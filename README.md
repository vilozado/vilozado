## Projects

**[TravelCrew](https://github.com/vilozado/TravelCrew)** &nbsp; [![Demo](https://img.shields.io/badge/Demo-F72585?style=flat-square&logo=youtube&logoColor=white)](https://www.youtube.com/watch?v=jdrAwScpedk)<br/>
Collaborative trip planner with calendar and map integration for group travel *(team of 3)*.
- Built with **React, Express, PostgreSQL**, deployed on **AWS** (EC2, RDS, Nginx reverse proxy + SSL)
- RESTful APIs with full CRUD for trips, activities, invitations and users
- Email invitation system with **Resend + JWT** for secure onboarding; **rate limiting** and **caching** for map-heavy load

**[PetAdopt](https://github.com/vilozado/PetAdopt/tree/dev)**<br/>
Legacy codebase refactor and test hardening *(team of 3)*.
- Refactored **JavaScript → TypeScript** for type safety and maintainability
- Contributed to **100+ unit, integration & E2E tests** (Vitest, SuperTest, Cypress) — **80%+ coverage**

**[Litlas](https://github.com/vilozado/Litlas)** &nbsp; [![Demo](https://img.shields.io/badge/Demo-F72585?style=flat-square&logo=youtube&logoColor=white)](https://www.youtube.com/watch?v=ERnae2dgKm4)<br/>
Independently built full-stack app for map-based, worldwide book recommendations.
- Built with **React, Node.js, Express, MongoDB, React-Leaflet** and the **Google Books API**
- Scalable **MVC** backend with RESTful CRUD APIs and in-memory caching
- **Stateless JWT auth with Redis-backed token storage** for horizontal scaling and centralized sessions
